# Security Policy

## Supported Versions

ReasonFlow is currently under active development.

Only the latest version is supported.

## Reporting a Vulnerability

If you discover a security issue within ReasonFlow, please do not create a public issue.

Instead, contact the maintainer directly with:

- Description of the vulnerability
- Steps to reproduce
- Expected behavior
- Potential impact

The issue will be investigated and addressed as quickly as possible.

## Third-Party Dependencies

ReasonFlow relies on several external services and libraries, including:

- Google Gemini API
- GitHub REST API
- Python Open Source ecosystem

Security of these services is outside the scope of this repository.
